# Entities

Entity IDs are generated by Home Assistant from the mower name. The examples below use a generic mower name.

## Control

- `lawn_mower.<mower>` / mower control (installations created before 1.1.0 keep the older `lawn_mower.<mower>_kosiarka` ID)
- `worx_vision_cloud.start_one_time_mowing` / translated service for one-time mowing with runtime, edge cutting and experimental zone selection
- `number.<mower>_czas_koszenia_jednorazowego` / one-time mowing runtime
- `select.<mower>_strefy_koszenia_jednorazowego` / one-time mowing zone or zone group
- `switch.<mower>_krawedzie_koszenia_jednorazowego` / start one-time mowing with edge cutting
- `button.<mower>_uruchom_koszenie_jednorazowe` / start one-time mowing using the selected runtime and zones
- `button.<mower>_odswiez` / request refresh
- `button.<mower>_reset_czasu_pracy_nozy` / reset blade runtime
- `button.<mower>_reset_cykli_baterii` / reset battery cycle counter
- `button.<mower>_uruchom_przycinanie_krawedzi` / start edge-only cutting
- `update.<mower>_firmware` / firmware version, release notes and OTA install when supported

## Schedule

- `sensor.<mower>_harmonogram`
- `sensor.<mower>_nastepne_zaplanowane_koszenie` / next enabled native weekly schedule start
- `calendar.<mower>_harmonogram_koszenia`
- `switch.<mower>_harmonogram_kosiarki` / enable or disable the mower's native schedule
- `number.<mower>_wydluzenie_czasu` / schedule time extension
- `number.<mower>_powierzchnia_trawnika` / lawn area
- `number.<mower>_obwod_trawnika` / lawn perimeter
- `number.<mower>_dystans_krawedzi` / Vision border-cut distance, when supported

return an old cumulative value. Estimated statistics update from locally
observed mower states and are explicitly approximate. Covered area includes
overlapping passes and is not the same as unique physical lawn area.

## Services

### `worx_vision_cloud.start_one_time_mowing`

Starts one one-time mowing run.

- `entity_id` - mower entity.
- `runtime` - mowing time in minutes, from `0` to `120`. Use `0` with `edge_cut: true` for an edge-only run; on Vision Cloud this is sent as the dedicated edge-cut command.
- `edge_cut` - edge cutting flag. Use `runtime: 0` with `edge_cut: true` for a dedicated edge-only run on Vision Cloud. The smart mowing blueprint starts edge cutting first, waits for a confirmed dock return, and then starts normal one-time mowing.
- `zones` - optional zone ID list, for example `[1, 2]`. Boundary-wire mowers support one selected zone. Vision/RTK firmware may ignore this field because the official app appears to use a different private cloud route. Leave it empty for default/all-zone mowing. When zones are sent to a Vision/RTK mower, a warning is written to the Home Assistant log.

Errors: every failure is raised as a Home Assistant error with a readable
message (mower offline, cloud connection not ready, cloud rate limit, command
not confirmed in time, login rejected). Scripts and automations can therefore
use `continue_on_error: true`. A rejected login also starts re-authentication.
A command that reached the Worx cloud is not reported as failed when only the
state refresh after it fails. The action is registered even while the Worx
cloud is unreachable; it then fails with "not loaded" instead of being missing.

Example:

```yaml
action: worx_vision_cloud.start_one_time_mowing
data:
  entity_id: lawn_mower.halina
  runtime: 60
  edge_cut: false
  zones:
    - 1
```

## Lawn mower state and attributes

States: `docked`, `mowing` (including edge cutting, status 32), `paused`,
`returning` and `error`. The state is `unknown` for statuses without a mapping
and `unavailable` when the mower is offline or the Worx cloud connection is
lost and cannot be re-established.

Attributes used by automations: `status_id`, `status_description`, `error_id`,
`error_description` (text from the Worx cloud, may be empty), `rain_delay`
(true/false) and `rtk_at_station` (true/false, or empty when the RTK position or
the station marker is unknown).

## Raw Entities

Raw payload entities are disabled by default. They are useful while reverse-engineering API fields, but they can be noisy and may expose private data. They can be turned on or off later in the integration options (`Settings > Devices & services > Worx Vision Cloud PLUS > Configure`); turning them off removes them.
